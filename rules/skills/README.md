# 操作技能

Skill用于整理可复用的专业方法、参考资料和脚本，例如Unity测试诊断。它不负责保证调度、权限或结果真实。

**当前状态：本目录尚无自动注册到Studio两位负责人或DSH的专用Skill。** 当前职责与工作方法主要来自roles文件、实际工具描述和任务指令。这里是统一维护入口，不表示已经实现Skill安装器或通用技能市场。

以后加入Skill时须核对对应Codex/DSH版本的官方加载方式，并验收实际发现、加载和触发行为；不能仅创建SKILL.md就标为已启用。内置模型运行环境可能另有技能/插件，本界面不枚举用户电脑全部技能，也不读取认证目录。
