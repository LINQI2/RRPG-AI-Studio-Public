# RRPG AI Studio

公开版本包含 Studio 工作台源代码及日常使用说明。开发会话和历史验证附件留在原开发环境。请用自己的运行环境和项目配置。

以中文沟通、研发成果和关键产品决策为中心的本地双负责人工作台。主开发负责技术拆包、委派、实现验证与集成；主策划负责设计质量与一致性。

**不知道文件在哪、该读哪份？从[仓库文档地图](docs/README.md)开始。** 按“我要做什么”定位资料；[文件职责清单](docs/CATALOG.md)区分现行手册、实际角色规则与历史报告，[状态入口](docs/STATUS.md)说明已知事实和待处理问题。

**AI首次接手入口：[AGENTS.md](AGENTS.md)**。它提供阅读顺序、使用说明位置和操作边界；人工直接从下方使用指南开始即可。

**查看或调整AI规则：[rules总入口](rules/README.md)**；网页从“设置 → AI规则与技能”进入，可查看完整角色规则并编辑两位负责人的补充要求。

**日常一键打开：双击根目录的 `打开工作台.cmd`。** 后台未启动时先启动并等待就绪，已运行时直接打开浏览器；不会重新初始化或重启正在运行的服务。也可在浏览器访问 http://127.0.0.1:3178/（后台须已运行）。

一键入口直接使用 Node.js，不执行 PowerShell 脚本，不需要修改 Windows 执行策略。

开启代理时，一键入口使用独立的 Edge/Chrome 普通浏览器窗口（保留地址栏与标签页）直连本机；不修改系统代理，也不更改 Codex/DSH 的网络配置。独立窗口首次使用时会重新建立网页会话，后台任务和聊天历史仍保留。

在 app 下使用 Node.js 24：npm ci、npm run build、./Start-Studio.ps1，打开 http://127.0.0.1:3178/。正常关闭使用 ./Stop-Studio.ps1。

从零上手请先读 [制作人使用指南](app/docs/USER_GUIDE.md)；AI接手读 [AI操作协议](app/docs/AI_OPERATOR_GUIDE.md)；所有说明见 [帮助目录](app/docs/INDEX.md)。启动和配置由维护者按 [运行手册](app/docs/RUNBOOK.md)处理。

已确认的设计主线：在外部ChatGPT讨论、确认并形成文档，由制作人或其授权AI代理指定负责人及审查/实施范围；负责人读取核对后自主协作，获准后由主开发/DSH实现验证，再汇报成果。让AI代操作时先读 [代理制作人说明](app/docs/PRODUCER_PROXY_GUIDE.md)。日常技术安排仍可直接聊天；一键文档交接尚有实现缺口，不能把流程说明当作已经全部实现。

新安装默认不配置工程、不自动初始化负责人。2026-10-22本机清理后已按制作人选择，将Pilot副本设为只读工作目录并显式初始化两位负责人；当前状态以设置为准。初始化不自动读取项目、派发任务或扩大执行权限。Unity由用户手动打开，配置后再核对身份。

历史归档位于本机 archive/2026-10-22-studio-experiments/，不参与运行、检索、导入或Git提交。认证、运行数据和快照不入Git。清理完成不表示正式游戏工程已接入。详见 [运行手册](app/docs/RUNBOOK.md)。
