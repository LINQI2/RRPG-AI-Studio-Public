# Unity MCP 兼容性修复

保留0.89.0插件和Unity Test Framework 1.1.33现场验证过的通用修复，未自动应用到任何新工程或升级插件：

- patches/plugin-filter.patch：允许全局命名空间测试类；修复明明存在的用例按类过滤却返回空。
- patches/plugin-result-count.patch：总数使用本次原生测试结果，不把完整发现树当本次执行数；通过状态要求原生Passed。
- patches/test-list-600-seconds.cs.txt：发现函数的600秒上限及明确超时异常；不能超时后返回空列表冒充没有测试。

需要时由主开发在已明确授权、版本一致的工程中审查并应用，等待实际编译并重新验证。补丁不包含固定工程路径、测试数量或特定游戏逻辑。

Studio端只有tests-run使用660秒HTTP预算，其他请求15秒；官方服务和插件超时不是同一层。不能推定所有冷发现/断线都因此安全完成；未知测试投递保留工程锁，核对实际结果后再决定后续操作。
