# Studio 帮助目录

本页负责“如何使用和维护工作台”。查全仓结构、需求与实现的区别、每份文件用途及历史报告，请到[仓库文档地图](../../docs/README.md)。本目录的日期化故障报告与旧HANDOFF属于历史证据，分类见[文件清单](../../docs/CATALOG.md)，不是当前初始化状态。

从不懂工作台开始，按下表阅读。说明按当前实现编写，历史规划只解释设计理由，不保证所有提议已实现。

AI首次进入Studio仓库时，先读根目录的 [AGENTS.md](../../AGENTS.md)，再按本文进入操作协议；根 [README.md](../../README.md)也提供同一导航。

主要设计路径：外部ChatGPT讨论 → 制作人确认并沉淀文档 → 制作人或获授权AI代理指定负责人、文档版本和审查/实施范围 → 负责人专业接手并自主协作 → 获准后开发/DSH实现验证 → 阅读成果并处理必要判断。普通技术安排仍可直接在工作台聊天。

代操作AI应先读代理说明，不能把“代为发送/跟进”理解为无限产品决定权；用户明确委托的代理验收也不应一律推回人工。当前程序缺口与安全限制见对应文档，不因主流程已确认就宣称一键文档交接已实现。

网页目前没有内置帮助导航；从项目根 README 或本页打开 Markdown 阅读。工作台内 AI 的文件工具只允许读取配置工程，**不会自动载入这些 Studio 文档**。向 AI 提供说明的方法见 AI 操作协议第1节。
